# MERIDIAN BAY — Golden Hour (Double Life)

A 3D low-poly open-world crime game, built with Three.js for the make.fun
gta6-01 bounty ("Make GTA 6").

Mara Voss is a double agent: the crew thinks she is their getaway driver,
the MBPD thinks she is their informant. Both are wrong. Drive the yellow
NIGHTHAWK through a sunset coastal city, run four undercover jobs, keep both
trust meters alive, and do not let Air One box you in.

## Play

Open `game/index.html` in a desktop browser (served over HTTP, no network
needed — Three.js is vendored under `game/vendor/`).

- **W A S D / arrows** — drive
- **E** — interact (grab the case on Pier 9)
- **1–4** — switch mission
- **R** — restart the current mission

## Missions

1. **DOUBLE LIFE** — lose the tail, hit every marker (wanted 4)
2. **SMOKE & MIRRORS** — cruise the boulevard, look innocent (wanted 1)
3. **THE HANDOFF** — reach Pier 9, grab the case (wanted 2)
4. **CLEAN GETAWAY** — run for the sunrise road, don't stop (wanted 5)
